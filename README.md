# 商いノート / sales-profit-tool

個人販売者・小規模EC向けの売上・利益管理MVPです。CSVを読み込み、全体のKPI、SKU別集計、月別グラフを表示します。日本語UI、ライト／ダーク／OS連動表示、PC・iPad mini向けのレスポンシブレイアウトに対応しています。

## 起動

依存ライブラリのインストール、バックエンド、データベース、APIキーは不要です。Python 3で静的ファイルを配信します。

```sh
cd sales-profit-tool
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。Python 3がある環境では `npm start` でも同じサーバーを起動できます。ES Modulesとサンプルの取得を使用するため、HTMLの直接オープンではなくHTTPサーバーを使ってください。

「サンプルで試す」で表示を確認するか、「CSVを選択」で自分のファイルを読み込みます。「集計CSVを保存」で全体・SKU別・月別の集計を1つのCSVとして保存します。iPadではダウンロード後にSafariのダウンロード一覧／ファイルアプリで確認してください。

## CSV仕様

UTF-8（BOM付き可）、最大10MB。ヘッダーは下記の5列が必須です。列順は自由で追加列は無視します。値の前後の空白は除去し、空行は読み飛ばします。カンマ区切り・引用符内のカンマ／改行／二重引用符に対応します。

```csv
SKU,販売数量,販売単価,仕入原価,販売日
BAG-001,8,4800,2600,2026-01-12
CUP-002,15,1800,700,2026-01-20
```

- SKU：空欄不可。同じ文字列を同一SKUとして集計します。
- 販売数量：0以上の整数。
- 販売単価・仕入原価：0以上の数値。仕入原価は1個あたり。通貨記号・桁区切り・指数表記は使えません。
- 販売日：実在する `YYYY-MM-DD` 形式の日付。
- 不正な行はCSVレコード番号と理由を表示し、ファイル全体の集計を中止します。以前の集計があれば保持します。引用符内の改行は1レコードとして数えます。
- 重複したデータ行も別の取引として数えます。返品などの負数には未対応です。

## 計算

- 売上 = 販売数量 × 販売単価
- 売上原価 = 販売数量 × 仕入原価
- 粗利益 = 売上 − 売上原価
- 粗利益率 = 粗利益 ÷ 売上 × 100。売上0円では「計算不能」。

集計後の金額から粗利益率を算出します（行ごとの率の平均ではありません）。月別はデータがある月を昇順で表示します。金額表示は小数点以下最大2桁、率は1桁です。内部計算はJavaScriptの浮動小数点数を使うため小数に微小誤差が生じる場合があります。安全な計算範囲を超える金額はエラーにします。税・送料・手数料は含まず、会計／税務用途の厳密な小数計算は対象外です。

## 構成

- `index.html` / `style.css`：ダッシュボード、レスポンシブ／テーマ表示
- `js/data.js`：ファイル取得、CSV解析・検証、CSVシリアライズ
- `js/aggregate.js`：DOMや取得元に依存しない集計関数
- `js/app.js`：画面、SVGグラフ、ダウンロード操作
- `sample.csv`：8件・3SKU・4か月のサンプル
- `tests/sales.test.js`：CSV／計算ロジックの回帰テスト

API連携を追加するときはデータ取得アダプターから `{sku, quantity, price, cost, date}` の配列を返し、同じ検証を経て `aggregateSales(rows)` に渡す構成にできます。

アップロードした内容は端末のメモリー内で処理し、外部送信・永続保存しません。リロードで消去されます。テーマ設定のみlocalStorageに保存します。SKUはHTMLとして解釈しません。出力CSVは引用符をエスケープし、ユーザー入力の表計算式の実行を抑止します。外部ライブラリ・フォント・CDNへの依存はありません。

## テスト

Node.js 22以降（開発時24.19.0）で実行します。

```sh
npm test
```

サンプルの期待値：売上342,000円、売上原価159,400円、粗利益182,600円、粗利益率53.4%、販売数量165点。ゼロ売上、赤字、小数、月／SKU集計、CSVの引用符・BOM・改行、不正入力、出力CSV、サイズ制限、計算範囲を検証します。

ブラウザでの確認手順：

1. 「サンプルで試す」で上記KPIと3SKU／4か月を確認。
2. 「集計CSVを保存」とサンプルCSVのダウンロードを確認。
3. 原価の空欄や不正な日付を含むCSVでエラーが出て、以前の集計を保持することを確認。
4. 売上0円のCSVで粗利益率が「計算不能」になることを確認。
5. テーマ切替、iPad mini 6の横画面（1133×744）・縦画面、PCで表とグラフを確認。

Chromiumで上記の主要操作と画面幅1440／1133／744／375pxを検証済みです。iPad mini 6の実機Safari検証は別途必要です。
